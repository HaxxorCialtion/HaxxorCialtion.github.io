Research, systems, and product

ICML 2026 · 第一作者

SimpleTool / RealtimeTool

Parallel Decoding for Real-Time LLM Function Calling

面向实时 Function Calling 的结构化输出压缩与多头并行解码方法。通过共享 Prefix / KV Cache， 让函数名与参数并行生成，减少串行自回归解码开销；在 Qwen 0.5B–14B 系列上验证，典型端到端加速 3–6×，最高 9.6×， RTX 4090 上 4B 模型达到 61.2 ms P50 Function Calling 延迟，约 16 Hz。

SimpleToolVLA

具身智能的结构化动作接口

将具身操作建模为语言定义的 Tool Calling，以带类型约束和连续参数的工具调用统一表达机器人动作与技能。 研究 LLM / VLM 高层策略与底层运动控制器的分层集成，在感知、决策、执行闭环中考察动作参数、实时延迟与任务泛化； 基于 MuJoCo 等仿真环境搭建桌面操作实验及数据合成、蒸馏流程。
