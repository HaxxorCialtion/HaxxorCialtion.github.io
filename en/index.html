Research, systems, and product

ICML 2026 · First author

SimpleTool / RealtimeTool

Parallel Decoding for Real-Time LLM Function Calling

A structured-output compression and multi-head decoding method for real-time function calling. Shared Prefix / KV Cache allows function names and arguments to be generated concurrently, reducing serial autoregressive overhead. Across Qwen models from 0.5B to 14B, it achieves 3–6× typical end-to-end speedup and up to 9.6×; a 4B model reaches 61.2 ms P50, or about 16 Hz, on an RTX 4090.

Ongoing · LLM / VLM as Policy

SimpleToolVLA

Structured action interfaces for embodied intelligence

SimpleToolVLA models embodied operation as language-defined tool calling, using typed tools with continuous parameters to express robot actions and skills. The work studies how high-level LLM / VLM policies integrate with low-level motion controllers, and evaluates action parameters, real-time latency, and task generalization in the perception–decision–execution loop. MuJoCo-based tabletop experiments support data synthesis and distillation.

Startup · On-device AI game engine

SimpleFun

One model · One phone · Infinite small worlds

SimpleFun connects AI play, AI creation, and AI remix through one mini-app protocol. A small model on the phone outputs dialogue, expression, inner state, and action together; the AI-UGC engine turns images, audio, and text into playable games; the Remix engine modifies existing games with a real-engine playtest gate. The current system has 100+ runnable mini-apps, with a 0.8B model bundled and 2B / 4B models downloaded on demand. The public product entry remains simplelove.fun.
